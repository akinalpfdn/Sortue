# Sortue — App Store listing (th)

## Name

```text
Sortue: เรียงสีไล่เฉด
```

## Subtitle

```text
เกมปริศนาโทนสีแสนผ่อนคลาย
```

## Promotional Text

```text
เติมสีสันเล็กน้อยให้ใจปลอดโปร่ง เรียงไล่เฉดสีสวยๆ ค้นหาจังหวะของคุณในโหมดสบายๆ หรือทดสอบสายตาในโหมดแม่นยำและบริสุทธิ์
```

## Description

```text
เติมความเป็นระเบียบเล็กๆ ให้โลกของสีสัน

Sortue คือเกมปริศนาสีแสนผ่อนคลาย สลับช่องสีเพื่อคืนไล่เฉดสีที่สวยงาม มองให้ดี เปรียบเทียบเฉดสีข้างเคียง แล้วดูสีสันค่อยๆ เข้าที่

สามวิธีในการเล่น

สบายๆ
เล่นตามจังหวะของคุณ เลือกขนาดตารางตั้งแต่ 4x4 ถึง 12x12 ดูตัวอย่างไล่เฉดที่เสร็จแล้ว และใช้คำใบ้เมื่อต้องการตัวช่วย

แม่นยำ
ทุกการเดินมีความหมาย ผ่านแต่ละปริศนาภายในจำนวนการเดินที่จำกัด และตารางจะใหญ่ขึ้นตามความก้าวหน้าของคุณ

บริสุทธิ์
เชื่อในสายตาของคุณ ไขปริศนาโดยไม่มีคำใบ้ ไม่มีตัวอย่างเฉลย และไม่มีเครื่องหมายบอกช่องที่วางถูกแล้ว

ส่วนผสมใหม่ในทุกปริศนา

สำรวจสีพาสเทลนุ่มนวล สีน้ำเงินเข้ม โทนอบอุ่นของยามเย็น และอีกมากมาย ไล่เฉดสีที่สร้างขึ้นใหม่นำชุดสีสดใหม่มาสู่ปริศนาถัดไปของคุณ

รายละเอียดเล็กๆ ช่วงเวลาที่น่าพึงพอใจ

• สลับช่องสีด้วยการแตะหรือลาก
• ใช้มุมที่ตรึงไว้เป็นจุดอ้างอิง
• เพลิดเพลินกับเพลงบรรยากาศและการสั่นตอบสนอง
• เล่นออฟไลน์ได้บน iPhone และ iPad

ไม่ว่าจะอยากพักผ่อนกับสีสันเบาๆ หรือทดสอบการรับรู้อย่างจริงจัง ก็มีวิธีเล่นที่เข้ากับอารมณ์ของคุณ

ค้นหาจังหวะของคุณ คืนความกลมกลืน
```
