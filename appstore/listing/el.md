## Name


## Subtitle

```text
Χαλαρωτικό παζλ αποχρώσεων
```

## Promotional Text

```text
Λίγο χρώμα, καθαρό μυαλό. Τακτοποίησε όμορφες διαβαθμίσεις, βρες τον ρυθμό σου στο Χαλαρό ή δοκίμασε το μάτι σου στα Ακρίβεια και Καθαρό.
```

## Description

```text
Βάλε λίγη τάξη σε έναν κόσμο γεμάτο χρώμα.

Το Sortue είναι ένα χαλαρωτικό παζλ χρωμάτων όπου αλλάζεις θέσεις στα πλακίδια για να επαναφέρεις όμορφες διαβαθμίσεις. Κοίτα προσεκτικά, σύγκρινε τις γειτονικές αποχρώσεις και δες τα χρώματα να μπαίνουν στη θέση τους.

ΤΡΕΙΣ ΤΡΟΠΟΙ ΠΑΙΧΝΙΔΙΟΥ

Χαλαρό
Παίξε με τον δικό σου ρυθμό. Διάλεξε πλέγμα από 4x4 έως 12x12, δες την τελική διαβάθμιση και χρησιμοποίησε υποδείξεις όταν χρειάζεσαι λίγη καθοδήγηση.

Ακρίβεια
Κάθε κίνηση μετράει. Ολοκλήρωσε κάθε παζλ μέσα σε όριο κινήσεων, ενώ τα πλέγματα μεγαλώνουν όσο προχωράς.

Καθαρό
Εμπιστέψου το μάτι σου. Λύσε χωρίς υποδείξεις, χωρίς προεπισκόπηση της λύσης και χωρίς σημάδια στα σωστά τοποθετημένα πλακίδια.

ΝΕΟΣ ΣΥΝΔΥΑΣΜΟΣ ΣΕ ΚΑΘΕ ΠΑΖΛ

Εξερεύνησε απαλά παστέλ, βαθιά μπλε, ζεστούς τόνους ηλιοβασιλέματος και άλλα. Οι διαβαθμίσεις που δημιουργούνται φέρνουν φρέσκους χρωματικούς συνδυασμούς στο επόμενο παζλ.

ΜΙΚΡΕΣ ΛΕΠΤΟΜΕΡΕΙΕΣ, ΙΚΑΝΟΠΟΙΗΤΙΚΕΣ ΣΤΙΓΜΕΣ

• Άλλαξε πλακίδια με πάτημα ή σύρσιμο.
• Χρησιμοποίησε τις σταθερές γωνίες ως οδηγό.
• Απόλαυσε ατμοσφαιρική μουσική και απτική ανάδραση.
• Παίξε offline σε iPhone και iPad.

Είτε θέλεις ένα απαλό διάλειμμα με χρώμα είτε μια πιο απαιτητική δοκιμασία της αντίληψής σου, υπάρχει τρόπος παιχνιδιού για τη διάθεσή σου.

Βρες τον ρυθμό σου. Επανάφερε την αρμονία.
```
